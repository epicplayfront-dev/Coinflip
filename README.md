**Coin Flip game**

README
    Coin flip game is a tool used  when an (not truly) random 50-50 chance is needed to settle a dispute.

How to use
    two players/groups select between heads or tails
    click the button or the coin get a random 50-50 outcome
    the player/group who guessed the side that is facing up loses
